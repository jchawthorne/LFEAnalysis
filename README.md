# LFEAnalysis

The notebooks and codes here provide some tools to do 
(1) download data to match a catalogue of LFEs,
(2) stack the signals of those events, and
(3) determine some properties of the stacks.

To get started, the first few notebooks will analyse some data that's already been downloaded and organised.  
It's located here: https://drive.google.com/drive/folders/1FtmI7y4MoH1_2Hn7RlesN1hBlV2Wz_Rx?usp=sharing
You'll want to download that directory and leave it named 'LFEFocMech'
