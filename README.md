# LFEAnalysis

The Python notebooks and codes here provide some tools to 
(1) download data to match a catalogue of LFEs,
(2) stack the signals of those events, and
(3) determine some properties of the stacks and the individual LFE properties.

Note that the codes are by no means optimised or pretty.  They're just designed to be functional.

To get started, the first few notebooks will analyse some data that's already been downloaded and organised.  
It's located here: https://drive.google.com/drive/folders/1FtmI7y4MoH1_2Hn7RlesN1hBlV2Wz_Rx?usp=sharing
You'll want to download that directory and put it somewhere that Python will be able to access it.
